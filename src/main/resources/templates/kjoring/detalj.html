    Neste steg: kontroller og godkjenn

    • Feil: Bruksdata går ikke opp mot fakturagrunnlaget. Dette er en feil i forsystemet — kontakt forsystem-teamet. Se avstemming
    • Ukjent: Bruksdata kan ikke avstemmes (kjøringen er eldre enn avstemmingen). Se avstemming
    • OK: All bruksdata er med i fakturagrunnlaget. Se avstemming
    • Advarsel: Rader ikke fakturert. Se avstemming
    • OK: Ingen blokkerende funn.
    • Feil: Blokkerende funn. Se kontrollfunn
    • OK: Ingen advarsler.
    • Advarsel: Advarsler. Se kontrollfunn

    Etter godkjenning kan kjøringen eksporteres til regnskap. Den kan fortsatt forkastes før eksport.

    Godkjenning er låst til de blokkerende funnene er løst (forkast, rett data, generer på nytt).
