Avstemming bruksdata

Bruksdata fra import …

Ukjent import (kjøring generert før avstemming fantes).

Viser bare bruk som kom inn i forsystemet. Bruk som datavarehuset filtrerer bort (f.eks. inaktive avtaler) er ikke med.

Avstemmingen går ikke opp: noen bruksdata er verken fakturert eller forklart, eller fakturalinjer peker utenfor importen. Dette er en feil i forsystemet — kontakt forsystem-teamet.

All bruksdata er med i fakturagrunnlaget.
